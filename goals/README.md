# goals/

Things with a **target or a date**.

| File | Holds |
|---|---|
| `current-priorities.md` | What you're focused on now, with a horizon (this quarter, this semester). Has a `review_by` date |
| `long-term.md` | Multi-year objectives with target dates |

Test: if it has a target or a "by when", it's a goal. If it describes who you are, it's `profile/`.

Example: `current-priorities.md`.
