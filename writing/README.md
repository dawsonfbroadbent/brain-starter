# writing/

How your writing should sound, so an AI can draft in your voice.

| File | Holds |
|---|---|
| `principles.md` | Voice and style rules for everything you write |
| `email.md`, `linkedin.md`, ... | Channel-specific rules (add the channels you use) |
| `ai-prompts.md` | Reusable prompts you paste into AI tools |
| `examples/` | Real samples you approve as "this is my voice". Each links to the rules it shows |

Rules live in the `.md` files. `examples/` holds samples only.

Example: `principles.md`.
