# profile/

Durable facts about **who you are**. Things that rarely change.

| File | Holds |
|---|---|
| `identity.md` | Name, self-description, rough location, background, languages |
| `values-and-boundaries.md` | Values and hard limits that shape decisions everywhere |
| `working-style.md` | How you plan, collaborate, communicate, decide |
| `ai-preferences.md` | Standing rules for how AI agents should work with you |

Not here: goals (→ `goals/`), domain preferences like food or fitness (→ `life/`).

Example: `identity.md` and `ai-preferences.md` (fictional "Alex Example").
