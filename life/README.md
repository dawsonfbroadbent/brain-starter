# life/

Personal life outside work, at the level of detail you choose to record.

Suggested subfolders: `fitness/`, `food/`, `outdoors/`, `interests/`, `family/`, `style/`. Each holds an `overview.md` or `preferences.md`, plus individual records beside it.

Health, finances, and family details are **sensitive**: an agent flags them and asks before recording anything. Never record sensitive details about family members.

Example: `interests/overview.md`.
