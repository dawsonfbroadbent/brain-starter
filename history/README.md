# history/

What used to be true, and why things changed. Current records hold only current statements. Everything else lands here.

| Folder | Holds | ID |
|---|---|---|
| `decisions/` | Significant decisions: context, options, choice, date | `dec-YYYYMMDD-<slug>` |
| `changes/` | Statements that were replaced, moved out of current records (`status: superseded`) | `chg-YYYYMMDD-<slug>` |
| `lessons/` | Lessons from your own experience, linked to the event | `lesson-<slug>` |

Superseded records are searchable only when an agent opts in (the `brain-history` collection).

Examples: `decisions/dec-20260110-start-studio.md`, `changes/chg-20260301-acme-hours.md`.
