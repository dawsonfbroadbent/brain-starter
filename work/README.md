# work/

Your employment history and career direction.

| File / folder | Holds |
|---|---|
| `experience.md` | Résumé-level list: one line per role, linking to `roles/` |
| `roles/role-<org>-<title>.md` | One record per job: employer, title, dates, responsibilities |
| `career-direction.md` | Target roles and industries, and why |
| `portfolio.md` | Curated work to show others, linking to `projects/` |

Test: someone else employs you → `work/roles/`. You own the business → `ventures/`. A deliverable with an end → `projects/`.

Examples: `experience.md`, `roles/role-acme-ux-designer.md`.
