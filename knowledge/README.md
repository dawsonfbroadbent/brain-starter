# knowledge/

Reusable knowledge and frameworks you've learned, written so they apply beyond the place you learned them. Suggested subfolders: `frameworks/`, `ai-and-software/`, `business/`.

Not here: your own preferences (→ `profile/`), one-off course notes (→ `education/courses/`), a dated lesson from your own experience (→ `history/lessons/`).

Example: `fixed-scope-pricing.md`.
