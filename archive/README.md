# archive/

Whole records that are no longer active: a stopped project, a closed opportunity, a shut-down venture. They keep their original path under `archive/` (for example `archive/projects/proj-<slug>.md`) and get `status: archived` plus a one-line reason.

Archived records are searchable only when an agent opts in (the `brain-archive` collection).

Example: `projects/proj-recipe-app.md`.
