# crm/

A personal CRM: the people and organizations you work with. IDs are stable and equal the file name.

| Folder | One record per | ID |
|---|---|---|
| `people/` | Person: who they are, how you know them, current relationship | `person-<first>-<last>` |
| `companies/` | Outside organization | `co-<slug>` |
| `interactions/` | Meaningful meeting, call, or event. Events are never superseded | `int-YYYYMMDD-<slug>` |
| `opportunities/` | Open possibility: job, deal, partnership | `opp-<slug>` |

**Rule:** respectful and factual. Write only what you'd stand behind if the person read it. No one else's health, finances, legal matters, or family conflict, and nothing a client told you in confidence.

Examples (all fictional): `people/person-jordan-sample.md`, `companies/co-sample-bakery.md`, `interactions/int-20260115-jordan-sample-coffee.md`, `opportunities/opp-sample-bakery-website.md`.
