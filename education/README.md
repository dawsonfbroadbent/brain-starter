# education/

Schools, programs, courses, certifications, and how you learn.

| File / folder | Holds |
|---|---|
| `overview.md` | One line per degree or program, with dates |
| `<school>/<program>.md` | Detail for a program (optional) |
| `courses/` | One record per course worth remembering: term, what it covered, your takeaways |
| `certifications.md` | Certifications, with issuer and date |
| `learning-preferences.md` | How you learn best |

Reusable knowledge from a course goes to `knowledge/`; the course record links to it.

Example: `overview.md`.
