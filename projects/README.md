# projects/

One record per **bounded piece of work** (`proj-<slug>.md`): goal, state, dates, what it was done under, and a link to the repo or tracker.

Code and detailed task lists stay in their own repos and trackers. This record only links to them.

When a project stops, move it to `archive/projects/` with `status: archived`.

Example: `proj-portfolio-site.md`.
